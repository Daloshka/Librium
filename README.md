# Librium

Перехватывающий HTTP/HTTPS-прокси для тестирования безопасности.
Rust, первая цель Windows 10.

## Документация

Заметки для выстраивания понимания и написания точных промптов агентам.
Читать сверху вниз, ссылки внутри файлов ведут друг на друга.

### Основное

- [Архитектура](docs/architecture.md) — как устроен перехватывающий прокси,
  конвейер внутри программы, словарь библиотек Rust, план первых шагов.
- [Сеть](docs/network.md) — слои протоколов, путь пакета на Windows 10,
  детальная хронология HTTPS, UDP, ICMP, SMTP и другие протоколы.
- [Настройка прокси](docs/proxy-setup.md) — где Windows хранит настройки
  прокси, кто их читает, настройка конкретных программ, установка CA,
  проверка цепочки.
- [Практика](docs/practice.md) — пять ступеней от наблюдения к своему коду,
  проверенные команды с реальным выводом, чек-лист примитивов на Rust.

### Основы

Справочные заметки по вещам, которые встречаются в основных документах.

- [Реестр Windows](docs/basics/windows-registry.md) — что такое реестр,
  разница HKCU и HKLM, где что лежит, как читать и писать.
- [TCP handshake](docs/basics/tcp-handshake.md) — заголовок сегмента,
  три шага установления соединения, опции, что делает ОС, ошибки, закрытие.
- [Глоссарий протоколов](docs/basics/protocols.md) — определения Ethernet,
  Wi-Fi, IPv4, IPv6, ICMP, TCP, UDP, QUIC, DNS, TLS, HTTP, WebSocket, SMTP
  по слоям и что каждый значит для Librium.
- [Версии TLS](docs/basics/tls-versions.md) — от SSL 2.0 до TLS 1.3,
  чем 1.3 быстрее и безопаснее, почему 1.2 ещё жив, что поддерживать в Librium.
- [Сертификаты](docs/basics/certificates.md) — что значат CN, O, OU, C, ST, L,
  почему CN больше не главный, SAN, расширения, чтение цепочки.
