Подключение HTTPS

Прокси: 127.0.0.1:8080. Укажи его для HTTP и HTTPS в браузере или настройках Windows.

  1. Скачай CA и установи его в доверенные корневые сертификаты текущего пользователя.
  2. Перезапусти браузер и открой сайт. Firefox может требовать отдельного импорта CA.

Проверка из PowerShell:

curl.exe --ssl-revoke-best-effort --proxy http://127.0.0.1:8080 --cacert "$env:LOCALAPPDATA\Librium\ca.crt" https://example.com

После остановки ядра отключи прокси в Windows. История хранится на диске; очистка удаляет её. QUIC и certificate pinning не поддерживаются. Вкладка HTTP показывает реконструированное сообщение, а не исходные TCP-байты.

Сервер Порт
  1. Пока прокси на телефоне выключен, открой эту ссылку в браузере телефона и скачай CA:
  2. iPhone: установи загруженный профиль, затем Основные → Об этом устройстве → Доверие сертификатам → полное доверие Librium Local CA.
    Android: в настройках безопасности найди установку сертификата CA и выбери скачанный файл.
  3. В настройках домашнего Wi-Fi на телефоне выбери Прокси → Вручную. Введи сервер и порт сверху, без аутентификации.
  4. Открой https://example.com в браузере телефона. Запрос появится в общей истории.

Если ссылка не открывается, разреши TCP 8080 и 8081 для частной сети в брандмауэре Windows. Кнопка копирует команду для PowerShell от администратора. Гостевой Wi-Fi, изоляция клиентов и VPN могут мешать соединению.

После работы отключи прокси в телефоне. Приложения с certificate pinning или без доверия к пользовательским CA могут не работать через HTTPS-прокси. При закрытии Electron доступ телефона выключается.

Трафик приложения · окна и главный процесс

Librium читает HTTP и WebSocket через локальный отладочный порт приложения. Сообщения сохраняются в общей истории. Для этого режима сертификат CA не нужен.

Выбери .exe Electron или package.json проекта, например Morphius.

Приложение ненадолго ждёт подключения Librium. Если подключение не удалось, отдельный помощник снимет ожидание примерно через 12 секунд. Запросы окон записываются после подключения их источника.

При запуске приложения: окна — 9333, главный процесс — 9334.

Полностью закрой выбранное приложение, включая значок в трее, перед запуском с захватом. Уже запущенный экземпляр может проигнорировать отладочные порты. Для проекта должны быть установлены зависимости Electron.

Захват отключён

Для другого Electron / Chromium приложения добавь к команде запуска --remote-debugging-port=9333 --remote-debugging-address=127.0.0.1, затем подключись к источнику «Окна / workers».

Для запросов главного процесса / Node.js добавь --inspect=127.0.0.1:9334 --experimental-network-inspection и подключись к источнику «Главный процесс / Node.js» на порту 9334. При запуске приложения кнопками выше включаются оба источника.

Записываются новые подключения после начала захвата. Для существующего WebSocket переподключи клиент. Источник Node.js читает поддерживаемые запросы fetch / http / https. Тела fetch / Undici сохраняются с отметкой полноты. Для встроенного WebSocket и отдельного пакета ws устанавливается временный наблюдатель. Он снимается при отключении. Библиотеки внутри bundle и нативные сокеты могут быть недоступны. Electron net и нативные модули могут не попадать ни в один отладчик. Отключение захвата оставляет приложение открытым; для закрытия отладочного порта перезапусти его обычным способом.

Значения поля протокола

Вся запись соединения, независимо от страницы и фильтров. До 100 самых частых значений. Байты поля должны быть сохранены целиком; неполный хвост, невалидный UTF-8 и служебные кадры исключены. Импорт схемы полей

Вставь JSON из кнопки «Копировать схему». Применение заменит текущий черновик и покажет поля на открытом сообщении. Сохранённые схемы изменятся только после нажатия «Сохранить схему».

Только описание полей: имена, типы, смещения, порядок байтов и длины. Код и значения трафика не принимаются.

Поля протокола

Это заданная тобой схема, а не автоматическое определение протокола. Смещения — от начала исходного сообщения, независимо от диапазона разбора и распаковки. bytes — Hex, utf8 — строгий UTF-8 фиксированной длины; int / uint — целые, float — числа с плавающей точкой. До 64 полей со смещением в первых 64 КиБ. Недостающие байты не угадываются. Сохраняются только настройки схемы, без значений сообщений. В таблице — первые 160 символов; копируется полное значение.

Поля JSON

«Копировать путь» копирует адрес поля в JSON. «Найти поле» покажет сообщения этого соединения, где такое поле существует. Значения сокращены до 160 символов.

Сигнатуры WebSocket

До 20 сигнатур на этом устройстве. Сохраняются только имя, маска, тип и направление; соединение и другие байты пакетов не сохраняются. «Применить» запускает поиск, но не сохраняет изменения формы.

Записанные окна и потоки

Весь архив независимо от фильтров истории. Одинаковые названия могут относиться к разным подключениям. Новые записи появятся после «Обновить».

HTTP и WebSocket — число записей истории, а не сообщений. WebSocket включает незавершённые попытки. «Выбрать» добавит точное условие к фильтрам истории.

Поиск WS по архиву

Сообщения всех записанных соединений, включая переподключения. Фильтры списка истории сюда не переносятся. Фрагмент сокращён; «Открыть» показывает исходный сохранённый пакет.

Контекст сообщения WS

Исходный порядок записи в одном соединении, оба направления и служебные кадры. Поиск и фильтры не применяются. Близость сообщений сама по себе не означает пару запрос / ответ. Фрагменты сокращены; «Открыть» загружает сохранённый пакет.

Содержимое WebSocket

Вся запись соединения, независимо от поиска и страницы. Одно сообщение относится к одной группе; первые примеры каждого направления открывают исходный пакет. Признаки помогают выбрать способ разбора и не устанавливают протокол приложения. Сжатые потоки не распаковываются автоматически.
