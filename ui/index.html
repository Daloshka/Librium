HTTPS setup

Proxy: 127.0.0.1:8080. Set it for HTTP and HTTPS in the browser or in the system network settings.

  1. Download the CA and install it into the trusted root certificates of the current user.
  2. Restart the browser and open a site. Firefox may need a separate CA import.

If the system proxy does not work (VPN tunnels and some apps ignore it), open a separate browser profile that goes through Librium directly:

Check from PowerShell:

curl.exe --ssl-revoke-best-effort --proxy http://127.0.0.1:8080 --cacert "$env:LOCALAPPDATA\Librium\ca.crt" https://example.com

After stopping the core, turn the proxy off in the system or the browser. The history is kept on disk; clearing deletes it. QUIC and certificate pinning are not supported. The HTTP tab shows a reconstructed message, not the original TCP bytes.

Phone · home Wi-Fi

The phone and the computer must be connected to the same home router. The computer may be on a cable.

Checking the network…

Server Port
  1. While the proxy on the phone is still off, open this link in the phone browser and download the CA:
  2. iPhone: install the downloaded profile, then General → About → Certificate Trust Settings → full trust for Librium Local CA.
    Android: in the security settings find CA certificate installation and pick the downloaded file.
  3. In the home Wi-Fi settings on the phone choose Proxy → Manual. Enter the server and port from above, without authentication.
  4. Open https://example.com in the phone browser. The request shows up in the shared history.

If the link does not open, allow incoming connections for Librium in the firewall. Guest Wi-Fi, client isolation and VPNs can break the connection.

When you are done, turn the proxy off on the phone. Apps with certificate pinning or without trust for user CAs may not work through an HTTPS proxy. Closing Electron turns phone access off.
