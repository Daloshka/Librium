Connect a device

Librium shows the traffic that goes through its proxy. Send the traffic to it, then trust its certificate so that HTTPS can be read.

1Send traffic through the proxy

The quickest way: a separate Chrome window that already goes through Librium. It works behind a VPN too.

By hand: set this address as the HTTP and HTTPS proxy in the browser or in the system network settings: 127.0.0.1:8080

2Trust the certificate to read HTTPS

Download the CA and install it into the trusted root certificates of the current user.

Restart the browser and open a site. Firefox may need a separate CA import.

3Check that requests arrive

Check from PowerShell:

curl.exe --ssl-revoke-best-effort --proxy http://127.0.0.1:8080 --cacert "$env:LOCALAPPDATA\Librium\ca.crt" https://example.com

After stopping the core, turn the proxy off in the system or the browser. The history is kept on disk; clearing deletes it. QUIC and certificate pinning are not supported. The HTTP tab shows a reconstructed message, not the original TCP bytes.

The phone and the computer must be connected to the same home router. The computer may be on a cable.

  3. Wi-Fi proxy
    iPhone: Settings → Wi-Fi → ⓘ next to the network → Configure Proxy → Manual.
    Android: Wi-Fi → ⚙ next to the network → Proxy → Manual.
    Server and port from above, no authentication.
  4. Open https://example.com on the phone: the request shows up in the history.
